## Cannon Projectile Motion – React + TS + Vite

This project is built with React (TypeScript) using Vite, styled with Tailwind CSS, and utilizes shadcn/ui components.

## Tech Stack

- Framework: React + Vite

- Language: JavaScript / TypeScript

- Styling: Tailwind CSS

## Getting Started

### 1. Prerequisites

- Node.js: v20.19+ or 22.12+
- Package manager: npm / yarn / pnpm

```sh
node -v
npm -v
```

### 2. Clone the Repository

```sh
 git clone https://github.com/sandeshsonel/cannon-projectile-motion
 cd cannon-projectile-motion
```

### 3. Install Dependencies

```sh
npm install
# or
yarn install
# or
pnpm install
```

### 4. Run the Project

```sh
 npm run dev
```

Visit:

http://localhost:5173

### 5. Build for Production

```sh
 npm run build
```

### 6. Preview the production build:

```sh
npm run preview
```
